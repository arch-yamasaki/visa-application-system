# Chrome Web Store 0.2.0 申告内容

最終更新: 2026-08-15

## 単一目的

所属組織のvisa-appに保存された在留資格申請情報を読み込み、利用者の明示操作により、出入国在留管理庁の在留申請オンラインシステム（RASENS）の対象申請フォームへ入力する作業を補助します。本拡張機能は申請の最終送信を行いません。

## 権限の利用理由

| 権限 | Developer Dashboard向け説明 |
| --- | --- |
| `identity` | visa-appのブラウザログイン画面を `chrome.identity.launchWebAuthFlow` で開き、Googleログインまたはメール・パスワードログインの完了後に、拡張機能専用の `chromiumapp.org` リダイレクトURIで認証結果を受け取るために使用します。Google APIのプロフィール、メール、ファイル等を読み取る目的では使用しません。 |
| `activeTab` | 利用者が「一括入力」または「ゆっくり入力」を実行したとき、現在選択しているタブがRASENSの対象画面かを確認し、複数のRASENSタブがある場合に入力先を限定するために使用します。 |
| `scripting` | 拡張機能の更新・再読込後などに対象のRASENSタブへ同梱済みの `content.js` が未接続の場合、パッケージに含まれる同スクリプトを再注入して入力機能を有効にするために使用します。外部コードは注入しません。 |
| `storage` | メールアドレス、Firebase認証トークン、選択した案件ID、visa-appから読み込んだ入力行、および入力可能状態を利用者のChromeプロファイル内に一時保存するために使用します。ログアウト時に認証情報と入力行を削除します。 |

## ホスト権限の利用理由

| ホスト | Developer Dashboard向け説明 |
| --- | --- |
| `https://www.rasens-immi.moj.go.jp/*` | RASENSの対象申請フォームを検知し、利用者が明示的に入力操作を実行したときだけ、visa-appから読み込んだ値をフォームへ設定するために使用します。一般的な閲覧履歴の収集や申請の最終送信は行いません。 |
| `https://visa-app-913363513517.asia-northeast1.run.app/*` | 認証済み利用者の所属組織に紐づく案件一覧および選択案件の申請フォーム入力データを、HTTPSのvisa-app APIから取得するために使用します。ブラウザログイン画面と公開プライバシーポリシーも同じホストで提供します。 |
| `https://identitytoolkit.googleapis.com/*` | Firebase Authenticationのメール・パスワード認証に使用します。入力されたパスワードはFirebaseへ直接送信され、拡張機能には保存しません。 |
| `https://securetoken.googleapis.com/*` | Firebase Authenticationの認証トークンを期限前に更新し、visa-app APIへのログイン状態を安全に維持するために使用します。 |

## リモートコード

「リモートコードを使用していない」を選択します。実行するJavaScriptは提出ZIP内の `api_client.js`、`popup.js`、`content.js` のみです。外部サービスから取得したJavaScript、WebAssembly、文字列化されたコード、設定値等を実行しません。

## データ利用申告

少なくとも次の区分を、Dashboardに表示される最新の選択肢へ対応付けて申告します。

- 個人を特定できる情報: メールアドレス、氏名、住所、電話番号、生年月日、国籍・地域、旅券番号その他の公的識別情報
- 認証情報: パスワード（Firebaseへ直接送信、非保存）、Firebase ID token、refresh token
- フォームデータ / ウェブサイトのコンテンツ: RASENSへ入力する学歴、職歴、勤務先、雇用条件、在留歴、取次者情報その他の申請項目
- 利用者操作に関する情報: 選択案件ID、入力可能状態、入力対象行。一般的な閲覧履歴、広告識別子、位置情報は収集しない

データ利用の認証項目は、次のすべてに該当するものとして選択します。

- 単一目的である入力補助の提供・改善にのみ利用する
- パーソナライズ広告、リターゲティング広告、関心ベース広告に利用しない
- データブローカー、広告事業者その他の第三者へ販売・移転しない
- 信用判断または融資目的に利用しない
- 利用者の個別同意、セキュリティ、法令対応等の許容された場合を除き、人が利用者データを閲覧しない

## Store listing用説明

所属組織のvisa-appから在留資格申請データを読み込み、出入国在留管理庁のRASENS申請フォームへ、利用者の操作で入力する社内向け補助ツールです。メール・パスワードまたはGoogleログイン、組織内の案件一覧取得、選択案件の読込、一括入力、ゆっくり入力に対応します。申請の最終送信は行いません。

本拡張機能は、認証のためメールアドレス、パスワードおよび認証トークンを処理し、入力補助のため氏名、住所、旅券情報、学歴・職歴、勤務先・雇用条件その他の申請フォーム情報を処理します。認証はGoogle Firebase、案件データはvisa-appとHTTPSで通信します。読み込んだ入力行はChromeのローカルストレージへ一時保存し、RASENS入力補助以外の目的、広告、販売、追跡には利用しません。詳細はプライバシーポリシーをご確認ください。

## 公開設定

- 初期運用の対象が組織内利用者に限られる場合は、現行の公開範囲を維持する。
- 審査通過後の公開方法は、現行設定が自動公開なら自動公開、手動公開なら手動公開を維持する。
- RASENS側ではQA中も最終送信を行わない。
